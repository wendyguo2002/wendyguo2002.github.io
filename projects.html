01 · Research · Amazon Lab126 collaboration

Physics-Based Radar Data Synthesis

Generate controllable human and animal motion, place it in sensor-agnostic RF scenes, and use RFDT—a physically based differentiable RF ray tracer—to produce labeled radar training data.

  • Designed data across subjects, behaviors, and environments for activity recognition.
  • Collected real human and pet activities including walking, sitting, lying down, falling, and jumping.
  • Co-authored the forthcoming ACM MobiCom 2026 demo, Differentiable Radio Frequency Digital Twin.

02 · Research software

WiTwin Studio

Built simulation preparation workflows that connect interactive 3D scene authoring with a Python simulation backend.

  • Developed tools for graphics assets, motion matching, animation timelines, and interactive visualization.
  • Added natural-language agents with scene and motion tools for multi-step workflows.
  • Defined execution boundaries between read-only planning and scene-changing actions, with regression coverage and saved-scene restoration.

03 · UC San Diego CWC

CWC Research Intelligence Platform

Built an evidence-backed system for more than 20 faculty members, combining searchable profiles, monthly activity digests, and collaboration discovery.

  • Consolidated source evidence with identity verification and provenance.
  • Generated summaries, themes, and keywords with unsupported-claim checks and deterministic fallbacks.
  • Built a searchable WebHub, monthly GitHub Actions workflow, and a correction loop for user feedback.
